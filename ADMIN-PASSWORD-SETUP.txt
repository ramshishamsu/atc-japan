ATC JAPAN — ADMIN LOGIN FIX / NETLIFY SETUP

The admin password is NOT stored in admin.html or admin.js.
It is read securely by the Netlify Function from the environment variable ADMIN_PASSWORD.

In Netlify:
1. Open your ATC Japan site.
2. Go to Site configuration (or Project configuration) > Environment variables.
3. Add or update these variables:
   ADMIN_PASSWORD = your chosen strong password
   GITHUB_TOKEN = your GitHub personal access token (keep secret)
   GITHUB_OWNER = ramshishamsu
   GITHUB_REPO = atc-japan
   GITHUB_BRANCH = main
4. Save the variables.
5. Trigger a fresh production deploy (Deploys > Trigger deploy > Deploy site).
6. Open https://YOUR-SITE/admin.html in a private/incognito window and try the exact ADMIN_PASSWORD.

IMPORTANT:
- Do not paste ADMIN_PASSWORD or GITHUB_TOKEN into chat or public code.
- Password matching is exact; check for accidental spaces before/after the value.
- If you see "Incorrect password", the ADMIN_PASSWORD value in Netlify is different from what you typed.
- If you see a configuration or function error, check all five variables above and ensure the latest deploy succeeded.
- If the site is not hosted on Netlify, /.netlify/functions/vehicles will not work as-is.
